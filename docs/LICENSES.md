## Game art

All illustrations in `assets/art/` were generated specifically for this project with the image generation endpoint `gpt-image-2.5` (OpenAI-compatible `/images/generations`). They contain no third-party logos or copyrighted characters.

## 3D assets

All GLB files in `assets/models/` were procedurally modeled for this project in Blender 4.2.9 by Python scripts in `tools/blender/`. No downloaded or ripped 3D assets are included.

## Audio

All music, ambience and sound effects in `assets/audio/` are original algorithmic synthesis (numpy + ffmpeg). No external samples, loops or generative-audio services were used.
