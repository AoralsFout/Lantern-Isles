# 《灯屿行记》 Lantern Isles

> 在星鲸的梦里，替世界点一盏灯。

## 一、世界

世界并不在海上，而是在一头名叫「大肥鱼」的星鲸的梦里。
它把人间一盏盏灯火驮在背上，灯亮着，梦就浮起一座小小的箱庭。
后来守灯人离开了，四座箱庭的灯依次熄灭，星鲸也沉沉睡去。

你是一只刚醒来的小灯灵，名字叫「拾」。
怀里抱着一盏只剩最后一粒火种的纸灯。
你要走进星鲸的四段梦，收集散落的「余烬」，点亮四座心灯，
在梦的尽头找回守灯人，也找回这头鲸鱼的名字。

## 二、主题

**记忆不是留住过去，而是把光交给下一个人。**
每一章是一种失去的方式：一段未被记住的初见、一条没能走完的路、
一场没能等到的人、一句没能说出口的名字。玩家做的事情很小：走路、看见、
捡起一点光。但正是这些微小的动作，让沉睡的世界重新相信自己在被记得。

## 三、章节

### 第一章 · 苔庭 · 春眠
- 英文：Mossgarden / Spring Sleep
- 场景：一座漂浮在晨雾里的巨大苔庭。梯田、樱林、石阶、锦鲤池、半塌的鸟居、瀑布后的洞窟。
- 色彩：苔绿、樱粉、晨金、青瓷。
- 情感：初见与懵懂。这里是星鲸记得的**第一盏灯**。
- 核心记忆：守灯人「阿萤」在樱花树下为一只迷路的鲸崽点亮纸灯。
- NPC：
  - 「苔婆婆」——被苔藓覆盖的古老石灵，slow，说话像石头缝里渗出的水。给探索提示。
  - 「小萤」——樱花树下的少女回声，不记得自己是谁，只觉得灯很暖。解锁记忆《樱花树下的第一盏灯》。
- 目标：收集 3 枚余烬，登上山脊点亮「残灯」。可选 5 枚全收集。
- 地标：断鸟居 / 锦鲤池 / 瀑布洞窟 / 高脊残灯。

### 第二章 · 琥珀沙海 · 长夏
- 英文：Amberreach / Long Summer
- 场景：黄昏的沙漠箱庭。风蚀峡谷、狭缝通道、绳桥、绿洲集市、半埋的鲸骨、沙丘高台。
- 色彩：琥珀、赭石、绿洲青、深棕。
- 情感：旅途与告别。这里是星鲸记得的**一条路**。
- 核心记忆：守灯人领着商队在沙暴里走了一夜，鲸在天上看着，第一次梦见“远方”。
- NPC：
  - 「阿柘」——商队领队的回声，豪爽，总说“再走一程就到了”。解锁记忆《沙海里的鲸眼》。
  - 「铃」——在鲸骨里烤火的小女孩，收集风铃。解锁记忆《鲸骨客栈》。
- 目标：3 枚余烬点亮「残灯」。可选 5 枚。
- 地标：狭缝峡谷、绳桥、鲸骨客栈、风蚀拱门、沙海灯塔。

### 第三章 · 霜枝谷 · 静冬
- 英文：Frostvale / Silent Winter
- 场景：蓝调时刻的雪谷箱庭。雪松林、冻瀑、温泉、木屋、石桥、冰湖、悬崖灯塔。
- 色彩：冰蓝、雪白、松墨、窗口暖橙。
- 情感：等待与守候。这里是星鲸记得的**一个没有回来的人**。
- 核心记忆：守灯人留在暴风雪里，把灯塔点亮，让所有船回家。
- NPC：
  - 「小满」——趴在结霜窗边等姐姐的孩子。解锁记忆《窗边的灯》。
  - 「老周」——灯塔下的守夜人回声，记不清自己等了多久。解锁记忆《暴风雪里的灯》。
- 目标：3 枚余烬点亮「残灯」。可选 5 枚。
- 地标：雪村、冻瀑、温泉、石桥、冰湖、断塔。

### 第四章 · 星坠之穹 · 归夜
- 英文：Starfall / Homecoming Night
- 场景：漂浮在夜空中的碎裂群岛。虹桥、镜湖、发光植物、鲸骨拱门、螺旋断塔、星雨。
- 色彩：夜蓝、紫、青绿、古金。
- 情感：重逢与归还。这里是星鲸梦的**核心**。
- 核心记忆：守灯人一直留在梦里做最后的灯芯，她忘了自己的名字，只记得要等一个人来。
- NPC：
  - 「阿萤」——守灯人本人。她把自己点成了灯，已经不记得“阿萤”这个名字。解锁记忆《把名字还给你》。
  - 「鲸骨钟」——鲸骨拱门下的古老钟，敲响后听见星鲸的梦。解锁记忆《万灯归海》。
- 目标：收集 3 枚余烬，登上断塔点亮「心灯」，叫醒大肥鱼。
- 地标：断桥群岛、镜湖、鲸骨拱门、虹桥、螺旋断塔。

## 四、结局

四盏心灯亮起，星鲸的梦开始上浮。
在断塔顶端，你终于见到阿萤。她是一团小小的、快要熄灭的光。
你把怀里的纸灯递给她，说：「我找到你了。」
她想起自己的名字，也想起鲸鱼的名字。

你对着天空喊：「大肥鱼，醒醒！」
星鲸睁开眼。四座箱庭在它的背上重新亮起来，像四盏漂在晨光里的灯。
阿萤没有消失。她坐上你的纸灯，和你一起去看下一座还没做完的梦。

最后一行：
「后来，没有人再数过海上有多少盏灯。因为每一盏，都有人记得。」

## 五、章节结束文案（诗）

1. 春眠：*「花开的时候，世界轻轻翻了个身。」*
2. 长夏：*「路没有尽头，但灯会记得每一个脚印。」*
3. 静冬：*「雪落在灯上，像一句迟到了很久的回答。」*
4. 归夜：*「我把名字还给你，你把黎明还给我们。」*
